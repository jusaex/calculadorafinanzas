Responsable

Datos introducidos en las calculadoras

Los importes y porcentajes introducidos se procesan localmente en el navegador. No se envían a CalculadoraFinanzas ni se guardan en una base de datos.

Datos que recoge directamente este sitio

Actualmente no hay cuentas de usuario, formularios, boletines, analítica activa ni publicidad. CalculadoraFinanzas no solicita directamente nombres, correos, datos financieros ni otros datos personales.

Alojamiento

El sitio se publica mediante GitHub Pages. GitHub puede procesar información técnica necesaria para servir y proteger la web, como direcciones IP y registros de acceso, conforme a su declaración de privacidad.

Publicidad futura

Si se activa Google AdSense u otra herramienta que trate datos o utilice almacenamiento local, esta política se actualizará y se implantará el mecanismo de consentimiento correspondiente antes de cargarla.

Consultas

Consulta la página de contacto. No publiques información financiera, documentos ni otros datos sensibles en incidencias públicas.
